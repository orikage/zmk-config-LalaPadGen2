## 日本語入力 ⇔ 英語入力の切り替え（Windows / Microsoft IME）

Default レイヤー最下段、右手側に次の2キーを割り当てています。

```dts
&kp INT4   /* 元「変換」位置 : IMEオン（かな入力） */
&kp INT5   /* 元「無変換」位置 : IMEオフ（英数入力） */
```

- タスクバー表示が `A`（IMEオフ・半角英数字直接入力）の状態で `INT4` 位置を押す → `あ`（IMEオン・ローマ字でひらがな入力）
- タスクバー表示が `あ`（IMEオン）の状態で `INT5` 位置を押す → `A`（IMEオフ）

`Win + Space` は言語／IME自体の切り替えであり、今回のキーとは別物です。今回のキーは「Microsoft IMEを選択した状態のまま」日本語入力のオン・オフだけを切り替えます。

### 経緯：`LA(GRAVE)` は実機で反応しなかった

Microsoft公式ヘルプでは、英語(101/102)キーボード配列でMicrosoft IMEを使う場合、`Alt + `` ` ```（`&kp LA(GRAVE)`）が日本語入力オン・オフの切り替えとして案内されており、最初はこちらを採用していました。しかし実機検証の結果、`LA(GRAVE)` はIME切り替えに反応せず、一方で `INT5`（無変換位置、英数キー）はIMEオフとして機能することが確認できました。この結果を踏まえ、`INT4`/`INT5`（変換・無変換）のペアに戻しています。

- ZMK公式のWindows互換表では `INT4`/`INT5` は非対応キーとして扱われていますが、Microsoft IME側の設定（後述）を行うことで、このリポジトリの実機では安定して動作することを確認済みです
- `LA(GRAVE)` は環境によっては動作する可能性があるため、下記「JIS配列を使う場合」のセクションと合わせて代替設定として残しています

### 採用しなかった／見送ったキーと理由

- `LANG1` / `LANG2` : Windows上でIMEオン・オフとして動作する保証がない（`LANG1`=かな、`LANG2`=英数という挙動は主にmacOSの日本語入力の話であり、Windowsでの動作は保証されない）
- `LANG5`（半角/全角） : ZMK公式のWindows互換表で非対応。過去に本リポジトリでも試したが実機で無反応だった
- `LA(GRAVE)` : Microsoft公式ヘルプではWindows標準の切り替え方法として案内されているが、本リポジトリの実機検証では無反応だった（環境依存の可能性がある）
- `F6`〜`F10` : これらはIMEオン・オフではなく、変換候補の確定前文字列に対する変換操作（ひらがな/全角カナ/半角カナ/全角英数/半角英数）。Secondaryレイヤーにこれまで通り残しています

## Windows側で必要な設定

1. Windowsの設定から「時刻と言語」→「言語と地域」で「日本語」を言語として追加する
2. 日本語の入力方式（IME）として **Microsoft IME** を使用可能にする（追加時のデフォルトでも可）
3. LaLaPad公式ガイドの推奨に従う場合、そのキーボードのハードウェアキーボードレイアウトを **英語キーボード(101/102キー)** に設定する（「言語と地域」→「日本語」→「言語のオプション」→「キーボード」→「ハードウェア キーボード レイアウト」）
4. タスクバー右下の入力インジケーターでMicrosoft IMEを選択する
5. Microsoft IMEの設定を開き、「全般」→「キーとタッチのカスタマイズ」で、変換キーの動作を「IME−オン」、無変換キーの動作を「IME−オフ」に割り当てる（既に割り当て済みの場合は不要）
6. メモ帳などを開き、`INT4`/`INT5` を割り当てたキーを押して、タスクバー表示が `A` ⇔ `あ` で切り替わることを確認する

## JIS配列キーボード（Realforceなど）を併用する場合の注意

WindowsのハードウェアキーボードレイアウトはOS全体の設定であり、USB接続した複数のキーボードごとに完全に分離できない場合があります。そのため、JIS配列のキーボード（例: Realforce）とLaLaPad Gen2を同じPCで使い分ける場合は次の点に注意してください。

- Windowsの物理キーボード配列設定は、接続している複数のキーボード間で共有されることがある
- WindowsをUS(101/102)配列にすると、JIS配列のRealforceなど別キーボードの記号入力が刻印とずれる可能性がある
- 逆にWindowsをJIS配列にした場合、`Alt + `` ` ```（`LA(GRAVE)`）ではなく、`` ` `` 単体（`GRAVE`）が半角/全角キー相当としてIME切り替えに認識される場合がある

本リポジトリのデフォルト実装は `INT4`/`INT5`（変換・無変換）です。環境によって `LA(GRAVE)` や `GRAVE` 単体の方が動作する場合もあるため、`config/lalapadgen2.keymap` のDefaultレイヤーで該当キーを次のように変更して試すこともできます。

```dts
# デフォルト（変換・無変換、要Microsoft IME側のキー割り当て設定）
&kp INT4
&kp INT5

# US配列 + Alt+Grave を試す場合
&kp LA(GRAVE)

# JIS配列 + Grave単体を試す場合
&kp GRAVE
```

## 実機での確認手順

1. ビルドした右手側用のUF2ファイル（`lalapadgen2_right`）をLaLaPad Gen2の右側に書き込む
2. Windowsで入力方式をMicrosoft IMEに切り替える
3. メモ帳を開く
4. IME表示が `A` の状態で `INT4` 位置のキーを押す
5. 表示が `あ` になることを確認する
6. `aiueo` と入力して「あいうえお」に変換候補が出ることを確認する
7. `INT5` 位置のキーを押す
8. 表示が `A` になることを確認する
9. `aiueo` と入力して半角英字の `aiueo` がそのまま入力されることを確認する
10. F6〜F10（Secondaryレイヤー）、レイヤー切り替え、Space、Enter、Backspaceなど他のキーに影響がないことを確認する
